# OmindOS 项目首页统一格式

2026-10-09 用户确认：项目首页格式借鉴 [OmindOS Navigation 发行首页](https://github.com/maganrobotics-boop/OmindOS-Navigation-Release)，后续项目继续沿用。适用于 OmindOS 项目的发行仓 README。

## 固定阅读顺序

1. **项目名称与用途**：用一两句话说明适用机器人和主要任务。
2. **下载 Ubuntu 安装包**：突出一个普通用户推荐入口，写清版本、文件大小、系统和架构，以及包内包含什么、是否需要额外依赖。
3. **装好后能做什么？**：用三至五条具体功能说明当前包的能力，写明当前发行的验收范围。
4. **工作台长什么样？**：使用实际运行截图，简述左、中、右区域；标明截图版本以及与下载包的关系。
5. **自己的参数怎么改？**：三至四步说明导入、修改、写入及保存，并链接图文指南。
6. **需要登录吗？可以调用 API 吗？**：说明账号、离线条件、本机入口和客户程序调用方式，链接 API 文档。
7. **更多资料**：少量入口，通向专业指南、历史版本和常见问题。

## 写作与图片要求

- 标题清楚、句子简短，回答用户实际安装和使用时的问题。
- 首页突出一个完整安装包。校验文件、历史版本、SDK、源码、板卡固件和详细验收记录放入对应资料页。
- 图片采用可核实的实际界面或明确标注的示意图，使用仓库相对路径和有意义的替代文字。
- 导航、机械臂等项目借鉴结构，各自按当前功能写内容。依赖、平台范围和发行状态不能照搬。
- 区分已发行软件、开发预览、参考模型和客户实机。尚未完成的内容写在相应范围说明中。
- 新版本更新时核对下载链接、文件大小、架构、依赖、截图和 API 文档。
- 主机端交付目前以 Ubuntu 为主；Windows 按用户后续安排推进。
