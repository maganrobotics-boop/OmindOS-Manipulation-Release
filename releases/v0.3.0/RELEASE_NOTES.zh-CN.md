# OmindOS 统一工作台 0.3.0：差速与全向导航

**普通用户只需下载一个 Ubuntu 完整包**。三维工作台、双臂与腰部协同算法、两种底盘导航和运行依赖已包含在同一包中。Ubuntu 22.04 x86_64 自包含安装归档，完整解压后执行 `./OmindOS-Workbench`，无需另装 Python、ROS 2、Docker 或 Node.js。

底盘导航直接复用现有 nav3d_native 算法与平台命令联锁内核，支持差速轮与全向轮；提供地图、目标朝向、整机包络、路径显示、取消及急停。客户可配置地图原点、OccupancyGrid、速度上限、安全余量、完整 URDF、关节与 TCP 映射。质量与电机力矩参数不参与本版几何导航。

“导航到位后双手共同移动”先导航、对齐朝向，观测零命令及零位姿变化连续至少 0.6 秒，再调用 runtime.2 双臂与共享腰部规划。底盘停在确认的实际仿真位姿，双臂逐样本继续检查导航地图和世界障碍物。导航期间锁定其他运动；取消、急停、参数更新与连接丢失不继续双臂任务。

验收范围是本机几何仿真、运动学、路径规划及保守离散碰撞检查。定位来自几何仿真，不表示传感器定位或实机底盘驱动已接通；物理制动、抓取接触与动力学未验收。仅发 Ubuntu 包，Windows 后续升级。完整配置和操作见 NAVIGATION.zh-CN.md、PLANNING.zh-CN.md。

旧版标签与附件保留，升级不删除用户目录下已有配置。解压后 `./OmindOS-Workbench --verify` 核对内部文件；SHA256SUMS 校验下载文件。后端业务源码不随安装包发行。

客户程序可通过同一程序的本机 HTTP API 调用配置、规划和导航；前端界面可不打开，不需再安装独立算法包。说明和客户侧示例见本仓库 releases/v0.3.0/API.zh-CN.md。

79 项回归通过；Ubuntu 编译程序及独立解压包各通过 17 项桌面、9 项规划和 13 项导航检查；最终编译包通过 8 项浏览器交互检查与两种底盘的客户 API 示例。浏览器交互使用 SwiftShader 软件渲染并关闭测试阴影；真实 GPU 性能未验收。
