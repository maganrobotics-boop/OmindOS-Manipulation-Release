# OmindOS 机械臂统一工作台 0.3.1 · Ubuntu 正式版

**只需下载一个 Ubuntu 完整安装包。** 包内包含完整 RM75 整机 CAD、三维工作台、双臂与腰部规划、差速与全向底盘导航及运行依赖。Ubuntu 22.04 / 24.04 x86_64；无需另装 Python、ROS、Node.js 或 Docker。

## 本版更新

- 整机 CAD 可选 RM75-B、RM75-6FB、RM75-6F，保留真实机身、底盘及双七轴外观；请选择符合客户硬件的子型号。
- 简化碰撞模型为 28 个保守包围盒，批量筛选可能相交的配对后继续进行原有碰撞判定；保留关节、限位、停止和取消保护。
- 支持纯运动学配置：加载、保存、历史版本、点动和正弦预览；未知电机参数保持空值。
- 整机协同按钮使用当前模型的双 TCP 规划；支持双臂与腰部关节路径、共同位移和通过后的三维播放。
- 完整 CAD 的末端聚焦、软件停止/复位、390px 手机布局和重启恢复通过验收。

## 安装与首次使用

完整解压后，在包目录运行：

```bash
./OmindOS-Workbench
```

浏览器访问 `http://127.0.0.1:8085/`。左侧“整机 CAD”选择子型号，点击“加载整机 CAD 模型”，检查参数后点击“将以上参数写入程序”。已有客户配置不会因加载模型或升级而自动覆盖。

不打开界面也可运行 `./OmindOS-Workbench --no-browser`，用同一程序的本机 HTTP API 调用模型、参数、规划与导航。详细说明见本仓库 `releases/v0.3.1/API.zh-CN.md`。

## 验收和范围

128 项源码回归、10 项原浏览器回归通过；Ubuntu 原生包独立解压 46 项接口检查通过，安装版完整真实 CAD 界面 9 项通过（20/20 外观网格，页面错误与资源失败均为 0）。

正式发布由已验收 0.3.1-rc.1 晋级：仅更新包内版本/发布身份清单，程序、模型和前端文件逐字节不变；重新独立解压验证清单、启动版本及三种模型目录。SHA256 和详细证据见发行附件。

本版正式发行范围是**本机运动学、路径规划和几何仿真**。碰撞采用保守包围盒和离散采样；不保证连续碰撞或任意任务都可行。导航定位来自几何仿真，底盘停车后进行双臂规划。真机驱动、实际零位/力传感器标定、动力学和力控后续升级。浏览器验收使用 Chrome / SwiftShader，未宣称真实 GPU 性能。

普通点动/正弦是运动学预览；碰撞验证通过“规划”入口。软件停止不代替硬件急停，复位不会自动续跑。旧版标签和下载附件保留。
