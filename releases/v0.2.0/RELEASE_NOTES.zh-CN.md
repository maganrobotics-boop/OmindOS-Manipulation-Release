# OmindOS 统一机械臂工作台 0.2.0

双臂与共享腰部规划接入三维工作台，按客户完整 URDF、关节限位、TCP 与关节映射计算。原样复用 runtime.2 的双手协同规划内核，联合求解共享腰部与左右七轴；支持关节路径规划、双手共同位移、盒形环境障碍物、取消、软件停止和完整路径三维播放。

本正式版验收范围为固定底盘的运动学、路径规划和离散碰撞检查。仅发布 Ubuntu 22.04 x86_64 安装归档；动力学与 Windows 安装包后续升级。真机执行不在本次范围。

## 安装

下载 `omindos-workbench-0.2.0-linux-x64.tar.gz` 与同名 `.sha256` 文件，在 Ubuntu 22.04 x86_64 上运行：

```bash
sha256sum -c omindos-workbench-0.2.0-linux-x64.tar.gz.sha256
tar -xzf omindos-workbench-0.2.0-linux-x64.tar.gz
cd omindos-workbench-0.2.0-linux-x64
./OmindOS-Workbench --verify
./OmindOS-Workbench
```

完整解压后即可使用，无需另装 Python、ROS、Node.js 或 Docker。安装包 84,333,892 字节；SHA256：`eb1b5ecc8fd8f7f66c873bf66a1b69e07063d1f9ee4807557ae04ea78ed6ce3e`。保留全部运行库与资源，默认配置仍保存在用户目录的 `OmindOS/workbench-configurations`。

导入客户 URDF 后，在“客户规划配置”中设置共享腰关节、两臂各七轴顺序与 TCP 连杆。关节路径先记录起点，再编辑目标姿态；协同规划输入双手共同 XYZ 位移。运动学规划不要求质量、惯量或电机力矩数据。详细步骤与几何边界见包内 `PLANNING.zh-CN.md`。

## 功能边界

碰撞检查采用保守、有方向的包围盒和最多 0.01 rad 单关节增量的离散采样，可能拒绝实际可行路径，不保证采样间连续无碰撞。固定装配及祖先链相邻两个主体关节间采用结构排除，具体排除对随结果返回。缺失或不支持的碰撞几何直接拒绝。

基座、夹爪及非规划关节保持固定；夹持物尚未作为实体加入碰撞模型。六秒播放只用于观察，不表示控制时序、速度、加速度或动力学保证。碰撞验收适用于规划入口，原有点动和演示仍为运动学预览。软件停止不能代替硬件急停；未做真机、接触力、动力学或真实 ROS 2/DDS 验收。

旧 runtime.2 与 preview 发行版保持原附件和适用范围。
